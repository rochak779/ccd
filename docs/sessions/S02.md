## Lifecycle labels and relationships

The contracts permit these independent lifecycles: request approval (`AWAITING_RESPONSE`, `PARTIAL_EVIDENCE_MISSING`, `COMPLETE`, `SUPERSEDED`), response processing (`IDLE`, `RESPONSE_PROCESSING`, `FAILED`), item coverage (`NOT_EVALUATED`, `SUPPORTED`, `MISSING`, `UNREADABLE`), finding (`OPEN`, `RESOLVED`, `DISMISSED`) and proposal (`READY`, `STALE`, `RECORDED`, `REJECTED`). A proposal never changes the approved request status; a decision records the human action. Evidence links a real source locator to one known request item, while findings cite one or more retained sources. Organisation membership and deal access are separate records.
